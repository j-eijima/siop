SIOP テスト RP

Self-Issued OpenID Provider (OpenID Connect Core 1.0 7章) に認証リクエストを送り、 返ってきた ID Token をこのページ内で検証します。 各パラメータは編集できるので、仕様に反したリクエストを送ったときの OP の挙動も試せます。

    送信する認証リクエスト

    

  
    
    nonce と state は localStorage に控え、コールバック側で照合します。
    実機で試す場合は Mac の LAN アドレスでこのページを開いてください
    (client_id / redirect_uri の既定値は開いている URL から作られます)。
  
    
  
    
    既定のブラウザで開いてください。
    OP は redirect_uri を開くだけで、リクエストを始めたブラウザを指定できません。
    iOS は https を既定ブラウザに渡すため、別のブラウザで始めると応答が戻らず、
    nonce / state の照合に失敗します。
